# Deployment

The maintained deployment guide is [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). It describes the checked-in Docker Compose setup, required production environment, and gaps that need operator configuration.

Do not use old copies of the manual systemd/NGINX recipe or treat the Compose configuration as a complete public production deployment. See the [documentation audit](docs/DOCUMENTATION_AUDIT.md) for unresolved isolation and security findings.
